# 🧾 ระบบออกใบเสร็จรับเงินค่าเทอม วิทยาลัยอาชีวศึกษาสุพรรณบุรี (SPVC Smart Receipt Desktop System)

ระบบโปรแกรมเดสก์ท็อป (Windows Desktop Application) สำหรับ **งานการเงินและบัญชี วิทยาลัยอาชีวศึกษาสุพรรณบุรี** ออกแบบมาเพื่อ **การออกใบเสร็จรับเงินค่าเทอมที่ยืดหยุ่นที่สุด หน้าจอสะอาดตา (Ultra-Clean UI) ตัวหนังสือใหญ่ชัดเจนไม่ล้นขอบจอ** พร้อมระบบฐานข้อมูล **SQLite WAL (ACID) + รองรับ PostgreSQL** ที่อัดข้อมูลได้หลายแสนรายการอย่างปลอดภัย

---

## ✨ จุดเด่นและฟีเจอร์ครบถ้วนตามระบบจริง (`EX`) + ต่อยอดให้ยืดหยุ่นที่สุด

### 1. ⚡ หน้า 1: ออกใบเสร็จรับเงิน (รายบุคคล & ออกใบเสร็จแบบเดียวยกห้อง)
- **ทุกช่องเลือกเป็น Dropdown ตามภาพต้นฉบับ `EX`**:
  - `เลือกหลักสูตร` (Dropdown 6 หลักสูตร) ➔ กรอง `รายการค่าธรรมเนียม` (Dropdown 35+ รายการจริงของ อศ.สุพรรณบุรี) อัตโนมัติ
  - `ภาค/ปีการศึกษา`, `กรองห้องเรียน`, `เลือกนักศึกษา`, `คณะ`, `แผนกวิชา/สาขา`, `ชั้นปี/ห้อง` เป็น Dropdown ทั้งหมด
- **🏫 ออกใบเสร็จแบบเดียวยกห้อง (Batch Classroom Receipts)**:
  - เลือกรายการค่าธรรมเนียมใส่ตารางใบเสร็จเพียงครั้งเดียว แล้วกดปุ่ม **`🏫 ออกใบเสร็จยกห้อง / นำเข้าไฟล์รายชื่อ`**
  - **วิธีที่ 1**: เลือก `ชั้นปี/ห้องเรียน` จาก Dropdown (เช่น `ปวช.1/1`) เพื่อรันเลขใบเสร็จต่อเนื่องให้เด็กทุกคนในห้องพร้อมกัน และสร้างไฟล์ Word (`.docx` แบ่งหน้าอัตโนมัติ) รวมทั้งห้องในคลิกเดียว
  - **วิธีที่ 2**: กด **`📥 เลือกไฟล์ Excel/CSV รายชื่อเด็ก ➔ นำเข้า & ออกใบเสร็จยกห้องทันที`** ระบบจะนำเข้ารายชื่อเด็กเข้าฐานข้อมูลพร้อมออกใบเสร็จให้ทั้งไฟล์ทันที

### 2. 🎓 หน้า 2: ข้อมูลพื้นฐานของนักศึกษา (ค้นหา • เพิ่ม • แก้ไข • ลบ • นำเข้าไฟล์ Excel/CSV)
- แถบกรองข้อมูลด้านบนด้วย Dropdown (`เลือกคณะ`, `เลือกสาขา`, `เลือกระดับชั้น`) + ช่องค้นหา
- ฟอร์มจัดการข้อมูลนักศึกษาด้านล่างใช้ Dropdown ทั้งหมด พร้อมปุ่ม `💾 บันทึกเพิ่มใหม่`, `✏️ แก้ไขข้อมูลที่เลือก`, `🗑 ลบรายชื่อที่เลือก`, `🧹 CLEAR (ล้างช่อง)` และ `📥 นำเข้ารายชื่อจาก Excel/CSV`

### 3. 🧾 หน้า 3: รายงานใบเสร็จรับเงินประจำวัน & ยกเลิกใบเสร็จ (Void)
- เลือกวันที่ออกใบเสร็จจาก Dropdown (`📅 เลือกวันที่ออกใบเสร็จ`) เพื่อดูสรุปยอดรับชำระรายวัน และสั่ง **`🖨️ พิมพ์รายงานประจำวัน (.docx)`** หรือ **`🖨️ พิมพ์ใบเสร็จซ้ำ (.docx)`**
- แถบ **`🚫 ยกเลิกใบเสร็จ (Void)`** ด้านล่าง: พิมพ์เลขที่ใบเสร็จที่ต้องการยกเลิก (หรือคลิกเลือกจากตาราง) ระบุสาเหตุ แล้วกดยืนยันยกเลิกได้ทันที ระบบจะคืนยอดค้างชำระและบันทึกประวัติ Audit Log อัตโนมัติ

### 4. ⚙️ หน้า 4: ตั้งค่าระบบ & เพิ่ม/ลบตัวเลือก Dropdown ได้ทุกหมวด (3 แท็บสะอาดตา)
- **แท็บ 1 (`📋 ตั้งค่ารายการค่าธรรมเนียมตามหลักสูตร`)**: เลือกหลักสูตรจาก Dropdown แล้วเพิ่ม/แก้ไข/ลบ รายการค่าธรรมเนียมและราคาต่อหน่วยได้อิสระ
- **แท็บ 2 (`🏫 เพิ่ม/ลบตัวเลือก Dropdown`)**: สามารถเพิ่มหรือลบตัวเลือกของ **ทุก Dropdown ในโปรแกรม** ได้เองทั้งหมด ได้แก่:
  - `หลักสูตร (CURRICULUM)`
  - `คณะ (FACULTY)`
  - `แผนกวิชา / สาขา (DEPARTMENT)`
  - `ชั้นปี / ห้องเรียน (CLASS_LEVEL)`
  - `ภาค / ปีการศึกษา (TERM)`
  - `ตำแหน่งผู้รับเงิน (CASHIER_POSITION)`
- **แท็บ 3 (`🏛️ กำหนดเลขที่ใบเสร็จ & สำรองฐานข้อมูล`)**:
  - ตั้งค่า `ที่ทำการ (วิทยาลัยอาชีวศึกษาสุพรรณบุรี)`, `ตำแหน่งผู้รับเงิน (ครู / เจ้าหน้าที่การเงิน)`, `เล่มที่ใบเสร็จ (7006)` และช่วงเลขที่ใบเสร็จ `ตั้งแต่ 700605433 ถึง 700611000`
  - ระบบสำรองข้อมูล **SQLite Online Hot Backup (`.db`)**, **Full Backup (`.zip`)** และ **Safe Restore**

## 🚀 วิธีเปิดใช้งานโปรแกรม (Shortcut / .EXE)

2. **`Run_SPVC_Receipt.bat`** (ไฟล์ตัวเปิดโปรแกรมสำรอง)
3. หรือรันผ่านคำสั่ง Python:
   ```powershell
   python main.py
   ```
